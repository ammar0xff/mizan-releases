# Mizan installers · برامج تثبيت ميزان

Installers for Mizan workspaces that run on the client's own computer (single device) or
on a shop's network (LAN). Download the installer from your **owner panel**
(Workspace → تنزيل), together with your licence file (`Mizan - <workspace>.mzn`).

| File | For |
|---|---|
| `MizanSetup-<version>-windows.exe` | Windows 10/11 (64-bit) |
| `MizanSetup-<version>-linux` | Linux (x86-64, with a desktop) — `chmod +x` then run |
| `mizan-setup-<version>-linux-x86_64.run` | Linux servers, command line only |
| `SHA256SUMS.txt` | Checksums |

The same installer handles both modes; the licence decides which. Without a licence it
can't install anything.
